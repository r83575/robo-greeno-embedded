# Distance Sensor - Arduino IoT Cloud

## Description

ESP32 project that measures distance using an HC-SR04 ultrasonic sensor and uploads the values to Arduino IoT Cloud.

The dashboard displays the distance values in real time.

---

## Features

- HC-SR04 distance measurement
- Arduino IoT Cloud integration
- Real-time telemetry
- WiFi communication
- MQTT/TLS connection

---

## Components

- ESP32 DevKit
- HC-SR04 Ultrasonic Sensor
- WiFi Network

---

## How It Works

The ESP32 continuously measures distance values using the HC-SR04 sensor.

The values are uploaded to Arduino IoT Cloud and displayed on the dashboard in real time.
