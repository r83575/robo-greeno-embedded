Hexapod Leg Command Simulator

A browser simulation of one 3-DOF hexapod robot leg. Write a Python-style command, run it, and see how the Hip, Femur, and Tibia joints move visually.

Visual Leg Model

Hip / Coxa
Rotates the whole leg forward or backward.
Femur
Lifts or lowers the upper leg segment.
Tibia
Extends or retracts the lower leg segment.
3-DOF
Three degrees of freedom: one servo for each joint.

Controls

This simulator replaces the physical 3-servo hexapod leg when hardware is unavailable. It connects the Python commands from the lesson to a visual 3-DOF leg movement.

Write a Python Command

Supported examples: leg0.move_to((90,60,120)) or leg0.smooth_to(HexLeg.LIFT)

Generated Python Command

leg0.move_to((90, 90, 90))

Supported preset names: HOME, STAND, LIFT, EXTEND, RETRACT. You can also type a direct angle tuple.

Preset Angle Table

Preset Hip Femur Tibia Purpose
HOME 90° 90° 90° Safe neutral position
STAND 90° 60° 120° Weight-bearing position
LIFT 90° 30° 90° Foot lifted from the ground
EXTEND 135° 60° 120° Leg extended forward
RETRACT 45° 60° 120° Leg pulled backward
